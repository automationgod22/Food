# Khana Khajana - Royal Indian Heritage Restaurant

A pixel-perfect, luxurious website for **Khana Khajana** (Royal Indian Heritage Cuisine) built with Next.js, React, and bespoke AI-generated visual assets.

## ✨ Features

- **Hero Slider Carousel**: Dynamic multi-slide hero showcasing opulent Rajasthani palace dining, grand royal feasts, and ambient evening lounges with smooth auto-play and manual navigation.
- **Dynamic Sticky Header**: Transparent gradient on hero transitioning to warm cream on scroll with a morphing SVG wave (`nav-wave`) that dips underneath the royal brand emblem.
- **Spirit Section**: Cinematic culinary frame showcasing sizzling charcoal kebabs and bubbling Rogan Josh in a hammered copper handi.
- **Catering & Memories (Trio Cards)**: Interactive 3-card showcase of authentic culinary heritage, rustic palace ambience, and royal Indian hospitality with grayscale-to-color hover effects.
- **Rooted Heritage Section**: Grand palace staircase and peacock mural banner with classical serif typography.
- **Testimonials & Marquee**: Multi-platform ratings (Google, Zomato, Dineout, TripAdvisor), continuous smooth marquee review cards, and vintage spice cart illustration.
- **Luxury Dark Footer**: 3-emblem branding with gold royal crest, 25 Years of Excellence badge, multi-column navigation, and palace locations across major cities.
- **Floating Actions**: Direct WhatsApp quick-contact button.

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React](https://react.dev/)
- **Styling**: Vanilla CSS design system with CSS custom properties
- **Typography**: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) & [Poppins](https://fonts.google.com/specimen/Poppins)
- **Icons**: Custom SVG icons

## 📦 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/automationgod22/Food.git
   cd Food
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
